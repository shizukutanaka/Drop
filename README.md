# Drop - 画像生成Web UI

## 概要

Dropは、Stable Diffusionなどの画像生成AIを操作できる日本語対応Web UIです。

- GPU選択機能
- 生成履歴のエクスポート・クリア
- 画像ダウンロード
- 直感的なUI

## 主なファイル
- `drop-pro-ui.html` : メインのWeb UI（HTML/JS/CSS一体型）
- `.gitignore` : Git管理対象外ファイル設定
- `README.md` : このファイル

## 使い方
1. `drop-pro-ui.html` をブラウザで開くだけで動作します。
2. バックエンド連携やAPI経由のGPUリスト取得は、今後の拡張で対応可能です。

## 開発・拡張
- バックエンドAPI連携やUIカスタマイズも容易です。
- ご要望・バグ報告はIssue/PRでどうぞ。
